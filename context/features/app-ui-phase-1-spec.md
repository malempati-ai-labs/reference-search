# App UI Phase 1 Spec

## Overview

This is phase 1 of reference search application UI. Use the screenshot reference below how it should look like

## Requirements

- App should have a common header for all the pages.
- On the left side of Header it must contain a app title with logo or icon and on the right side it should contain two links Search and Add case study to navigate between those two pages.
- The default page of app should be Search page.
- The default page without any business logic but as shown in the referenced screen shot.
- Use installed TailwindCSS for creating reusable and responsive components
- Match the color scheme as close as possible as shown in the referenced screenshot
